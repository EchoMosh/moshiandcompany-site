# moshiandcompany.com

Static site for https://moshiandcompany.com, published with GitHub Pages from `main` (root).

- `index.html`: landing with two choices, For Brands / For Creators
- `brands/`: brand offer page (the former home page)
- `creators/`: creator page with sign-up form (posts to Supabase table `moshico_creator_signups` in project RR_Agent, insert-only public key)
- `assets/`: fonts and favicon
- `privacy-policy/`: privacy policy (copy of the old ChatGPT-hosted page)
- `CNAME`: custom domain

To update: edit, commit, push to `main`. Pages redeploys in about a minute.

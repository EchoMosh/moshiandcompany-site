# moshiandcompany.com

Static site for https://moshiandcompany.com, published with GitHub Pages from `main` (root).

- `index.html` + `assets/`: home page
- `privacy-policy/`: privacy policy (copy of the old ChatGPT-hosted page)

To update: edit, commit, push to `main`. Pages redeploys in about a minute.
